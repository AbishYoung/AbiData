# Keyboard shortcuts

The Mac column uses ⌘ (Command), ⇧ (Shift) and ⌥ (Option). Keys on Windows and Linux are shown with Ctrl. Press `?` anywhere outside a text field to open the documentation, or `Ctrl+K` / `⌘ K` for the command palette.

| Action | Mac | Windows / Linux | Where it applies |
|---|---|---|---|
| Open the command palette | `⌘ K` | `Ctrl+K` | Everywhere |
| Open the documentation | `?` | `?` | Everywhere, except while typing in a field |
| Close the focused tab | `Delete` | `Delete` | Tab strip |
| Save the design | `⌘ S` | `Ctrl+S` | Table design, queries, forms, reports, scripts, jobs |
| Move between cells and records | `Arrow keys` | `Arrow keys` | Datasheet |
| Next cell (Shift+Tab: previous cell) | `Tab` | `Tab` | Datasheet |
| Move one page up (PageDown: one page down) | `PageUp` | `PageUp` | Datasheet |
| Go to the first record | `⌘ Home` | `Ctrl+Home` | Datasheet |
| Go to the last record | `⌘ End` | `Ctrl+End` | Datasheet |
| Edit the current cell | `Enter` | `Enter` | Datasheet |
| Edit the current cell | `F2` | `F2` | Datasheet |
| Insert a line break in a long text cell | `⌥ Enter` | `Alt+Enter` | Datasheet cell editor |
| Save the record | `⇧ Enter` | `Shift+Enter` | Datasheet |
| Cancel the edit, or discard unsaved changes to the record | `Esc` | `Esc` | Datasheet |
| Go to the new record row | `⌘ ⇧ N` | `Ctrl+Shift+N` | Datasheet |
| Focus the filter box | `⌘ F` | `Ctrl+F` | Datasheet (elsewhere the browser's find) |
| Delete the selected records | `Delete` | `Delete` | Datasheet |
| Select or deselect the current record | `⇧ Space` | `Shift+Space` | Datasheet |
| Toggle a Yes/No cell | `Space` | `Space` | Datasheet |
| Resize a column (Alt+Left: narrower, Alt+Right: wider) | `⌥ →` | `Alt+→` | Datasheet column header |
| Save the record | `⇧ Enter` | `Shift+Enter` | Forms |
| Discard unsaved changes | `Esc` | `Esc` | Forms |
| Start a new record | `⌘ ⇧ N` | `Ctrl+Shift+N` | Forms |
| Previous record | `⌥ ↑` | `Alt+↑` | Forms |
| Next record | `⌥ ↓` | `Alt+↓` | Forms |
| Move the selected controls by one grid step | `Arrow keys` | `Arrow keys` | Form and report designers |
| Resize the selected controls | `⇧ Arrow keys` | `Shift+Arrow keys` | Form and report designers |
| Focus the next control (Shift+Tab: previous) | `Tab` | `Tab` | Form and report designers |
| Focus the next or previous control without selecting it | `⌘ Arrow keys` | `Ctrl+Arrow keys` | Form and report designers |
| Add or remove the focused control from the selection | `Space` | `Space` | Form and report designers |
| Select only the focused control | `Enter` | `Enter` | Form and report designers |
| Delete the selected controls | `Delete` | `Delete` | Form and report designers |
| Select all controls | `⌘ A` | `Ctrl+A` | Form and report designers |
| Duplicate the selected controls | `⌘ D` | `Ctrl+D` | Form and report designers |
| Clear the selection | `Esc` | `Esc` | Form and report designers |
| Previous or next page | `PageUp` | `PageUp` | Report viewer (PageDown: next) |
| First or last page | `Home` | `Home` | Report viewer (End: last) |
| Next search match | `Enter` | `Enter` | Job run log search |
| Previous search match | `⇧ Enter` | `Shift+Enter` | Job run log search |

AbiData never binds F1 or Ctrl/Cmd with N, T, W, E, L or P, so your browser keeps those.
