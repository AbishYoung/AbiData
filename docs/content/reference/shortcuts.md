# Keyboard shortcuts

The Mac column uses ⌘ (Command), ⇧ (Shift) and ⌥ (Option). Keys on Windows and Linux are shown with Ctrl. Press `?` anywhere outside a text field to open the documentation, or `Ctrl+K` / `⌘ K` for the command palette.

## Global

| Action | Mac | Windows / Linux | Where it applies |
|---|---|---|---|
| Open the command palette | `⌘ K` | `Ctrl+K` | Everywhere |
| Open the documentation | `?` | `?` | Everywhere, except in text fields, editors and datasheets |
| Open the context menu of the focused item (the same as a right-click) | `⇧ F10` | `Shift+F10` | Navigation pane, document tabs, datasheets, query results and designers |
| Save the design | `⌘ S` | `Ctrl+S` | Table design, queries, forms, reports, scripts, jobs |

## Navigation

| Action | Mac | Windows / Linux | Where it applies |
|---|---|---|---|
| Close the focused tab | `Delete` | `Delete` | Tab strip |
| Resize the panes on either side of a splitter | `Arrow keys` | `Arrow keys` | Splitters in the form and report designers (Shift: bigger steps) |

## Dialogs and panels

| Action | Mac | Windows / Linux | Where it applies |
|---|---|---|---|
| Move the highlight through the results | `Arrow keys` | `Arrow keys` | Command palette (Up and Down) |

| Go to the first result (End: last result) | `Home` | `Home` | Command palette (when the text cursor is already at the start, or at the end for End) |

| Go to the first search result (End: last result) | `Home` | `Home` | Documentation search results |

AbiData never binds F1 or Ctrl/Cmd with N, T, W, E, L or P, so your browser keeps those.
