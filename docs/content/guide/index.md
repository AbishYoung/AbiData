# Welcome

AbiData is a self-hosted database application platform. You build tables, queries, forms, reports and scripts in the browser, and the people you invite use them from any device. Everything for one project lives in a **workspace**, which is a single SQLite database on your server.

## How a workspace is organised {#organisation}

The navigation pane on the left groups objects by type:

| Object | What it is | Where to read more |
|---|---|---|
| Tables | Your data, shown as a datasheet | [Tables](/docs/guide/tables) |
| Queries | Saved selections, joins and totals | [Queries](/docs/guide/queries) |
| Forms | Screens for entering and viewing records | [Forms](/docs/guide/forms) |
| Reports | Printable, grouped output | [Reports](/docs/guide/reports) |
| Scripts | Lua code behind forms, reports and jobs | [Scripts](/docs/guide/scripts) |
| Jobs | Scripts that run on a schedule | [Jobs](/docs/guide/jobs) |
| API keys | Access for bots and other programs | [API access](/docs/guide/api) |

Each object opens in a tab. Builders and owners also get a view switcher on the tab (for example Datasheet and Design).

## Where to start {#start}

1. Create a table and add a few fields: [Tables](/docs/guide/tables).
2. Type some records into the datasheet, or [import a CSV file](/docs/guide/imports-exports).
3. Invite your team and choose their roles: [Members and roles](/docs/guide/members-and-roles).
4. Connect other programs with an [API key](/docs/guide/api).
5. Take a [backup](/docs/guide/backups) before making big design changes.

If you run the server yourself, start with [Install](/docs/operations/install).

## Finding help {#help}

- Click the **?** button in the top bar to open this documentation beside your work.
- Press `Mod+K` and choose **Open docs**.
- When an error dialog appears, use **Learn more** to jump to that error in the [error reference](/docs/reference/errors).
- Hover a function in Script Studio to link to the [Lua API reference](/docs/reference/lua-api).

See [Keyboard shortcuts](/docs/reference/shortcuts) for the full list of keys.
